# 🧠 Exercícios Iniciais de Programação em C#

Este repositório contém uma coleção de exercícios básicos desenvolvidos em **C#**, com o objetivo de reforçar os primeiros conceitos da linguagem e da lógica de programação.

## 📚 Conteúdo

Os exercícios abordam temas como:

- Sintaxe básica do C#
- Variáveis e tipos de dados
- Operadores aritméticos e lógicos
- Estruturas de decisão (`if`, `else`)
- Entrada e saída de dados
- Funções simples
